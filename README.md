# 녹화 자막 메이커

화면과 컴퓨터 소리를 녹화하고, AI(Whisper)가 영상 속 말을 받아 적어 자막을 달아 주는 웹 앱입니다.

**바로 쓰기:** https://npsg1215-gif.github.io/rec-caption-maker/

## 기능
1. **화면 녹화**: 화면과 컴퓨터 소리를 함께 녹화합니다. 마이크는 녹음하지 않습니다.
2. **자막 만들기**: AI가 영상 속 말을 받아 적습니다. 한국어, 영어, 일본어, 중국어를 지원합니다.
   - 정확도: "가장 정확"(기본) 약 99%, "보통" 약 95%, "빠름" 약 86% (소음 섞인 한국어 음성으로 측정)
   - 글꼴: 무료 한글 글꼴 10종 (모두 SIL 오픈 폰트 라이선스, 상업적 이용 가능)
3. **최종 검토**: 자막 글자와 시간을 바로 고치고, 자막을 끌거나 방향키로 원하는 위치에 옮길 수 있습니다.
4. **저장하기**: 자막 입힌 영상, 자막 파일(.srt), 원본 영상으로 저장합니다.
5. **예약 녹화**: 날짜와 시간(최대 4시간)을 정해 두면, 그 시간에 알아서 녹화를 시작하고 끝낸 뒤 자막까지 만듭니다.
   예약할 때 화면 공유를 한 번 허락해야 하고, 예약 시간까지 탭을 열어 두어야 합니다.

## 알아 두기
- Chrome 또는 Edge(PC)에서 써 주세요.
- 소리까지 녹화하려면 화면 선택 창에서 "전체 화면" 또는 "탭"을 고르고, "시스템 오디오 공유"를 켜세요.
- 영상과 소리는 **내 컴퓨터 안에서만 처리**되고, 어디에도 올라가지 않습니다.
- 처음 자막을 만들 때 AI 모델(약 200~600MB)을 한 번 내려받습니다.

## 내 컴퓨터에서 실행하기
Python이 설치된 Windows PC에서 `실행하기.bat`을 더블클릭하면 됩니다.
